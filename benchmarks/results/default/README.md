# Default-model comparison provenance

The current repository default is GPT-5.5 via Pi/Copilot with high reasoning.
This directory assembles **existing observed runs**, rather than claiming a new
simultaneous benchmark:

- `pi--github-copilot--gpt-5.5.json` is copied unchanged from
  `../gpt_high/pi--github-copilot--gpt-5.5.json`.
- `ollama--qwen2.5vl-3b.json` is copied unchanged from
  `../ollama--qwen2.5vl-3b.json`.
- `ollama--qwen2.5vl-7b.json` is copied unchanged from
  `../ollama--qwen2.5vl-7b.json`.

All three reports have identical input/system-prompt/manifest hashes. The
summary is generated by `python -m benchmarks.run --summarize-only`. Original
runs are preserved in their source directories.

`bash scripts/bench_mini.sh` re-runs the default comparison and updates this
directory. Adding `--resume` reuses matching completed runs without inference
calls. A single 16-example run does not establish a reliable model ranking.
